# 团队使用示例

## 判断位置，不执行写入

```text
使用 $lark-team-knowledge-router，判断这份测试报告应该放在哪。先不要移动。
```

预期行为：读取资源和实时目录，输出路由卡，不执行写入。

## 归档普通文件

```text
使用 $lark-team-knowledge-router，把这份文档归档到团队知识库的正确目录，并保留需要的业务入口。
```

预期行为：核验对象、负责人和目录，搜索重复项，移动唯一原稿，建立或复用入口并验证。

## 建立数据表和表单

```text
使用 $lark-team-knowledge-router，建立 POC 需求登记表单。原始数据放统一数据库，在 POC 知识库的正确项目目录增加入口。
```

预期行为：先定位或建立承载数据表，再创建表单，最后建设业务入口；不得在 POC 知识库复制第二份数据。

## 迁移旧多维表格

```text
使用 $lark-team-knowledge-router，把这个旧 Base 迁入晴天纪数据库。先盘点所有关联表，验证通过前不要停用旧表。
```

预期行为：盘点表和依赖，按业务文件夹与依赖顺序迁移，逐表报告状态，切换入口，保留源表。

## 修复根目录错误

```text
使用 $lark-team-knowledge-router，检查这个知识库根目录里的文件，把它们路由到正确目录。删除重复项前先让我确认。
```

预期行为：逐项生成路由卡，移动已授权对象；重复项只列为候选，不擅自删除。

## 缺少飞书插件或技能

预期提醒：

```text
当前环境缺少本次操作需要的飞书能力：<能力列表>。是否要安装或启用对应的飞书插件/技能后继续？
```

用户未同意安装前，不执行外部安装，也不假装已经读取飞书实时状态。
