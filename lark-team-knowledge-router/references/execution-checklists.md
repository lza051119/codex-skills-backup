# 写入、迁移与验证清单

## 普通文件写入前

- 已解析真实对象类型、token、标题、当前父节点和权限。
- 已读取目标知识空间实时目录树。
- 已明确唯一权威原稿和全部业务入口。
- 已搜索同名节点、同 token 入口和重复原稿。
- 已取得与动作相符的建议、执行或破坏性授权。

## Base 或表单写入前

- 已解析真实 Base token、table id、form id 和 folder id。
- 已区分 Base 应用、数据表、视图、表单和业务入口。
- 已盘点主表、明细表、配置表及其依赖。
- 已记录字段类型、关联目标、公式、Lookup、视图、自动化和权限。
- 已搜索现有同名或同用途对象，完成幂等判断。

## 迁移执行顺序

1. 建立或确认目标业务文件夹。
2. 迁移无依赖的主数据表。
3. 迁移依赖主数据的业务表。
4. 恢复关联、公式、Lookup、视图和自动化。
5. 对比记录数、关键字段和权限。
6. 建立并验证业务入口。
7. 将流量或使用说明切换到新入口。
8. 保留旧原稿，直到用户单独授权停用或删除。

## 完成定义

只有同时满足以下条件才能报告完成：

- 权威原稿存在于路由卡指定的真实父节点。
- 每个业务入口都存在于指定目录，并指向同一原稿。
- 没有因为本次操作产生第二份未标注的权威数据。
- 关联、公式、Lookup、视图、自动化和权限已逐项核对，或明确列出不适用项。
- 使用目标成员身份或可验证权限确认入口可访问。
- 部分失败已逐对象报告，源数据和旧入口仍可用。

## 禁止的完成表述

仅创建了目标对象、仅看到命令返回成功、或仅移动了一个节点，都不足以声称迁移完成。必须重新读取目标状态并按完成定义核对。
